# Jacob C. Kamholz Research Site

Personal academic and research website for **Jacob C. Kamholz, MPH, NRP**, focused on emergency medical services health services research.

Live site: https://jacobkamholz.github.io/

## Research focus

My work examines emergency medical services as a health system, with emphasis on:

- EMS workforce retention, turnover, job satisfaction, and organizational culture
- reimbursement, revenue capture, payment design, and EMS policy
- educational access, program performance, and geographic disparities
- EMS operations, service availability, behavioral health demand, and system performance

## About this repository

This repository contains the static files used to publish the site through GitHub Pages.

### Main files

- `index.html` — site content and structure
- `styles.css` — site styling and responsive layout
- `script.js` — navigation behavior and automatic footer year
- `404.html` — GitHub Pages error page
- `.nojekyll` — disables Jekyll processing

## Updating the site

Most content updates are made in `index.html`.

Styling changes are made in `styles.css`.

Changes committed to the `main` branch are automatically deployed through GitHub Pages.
